# Oppgave 9: Sette sammen et lag

Målet er å bruke en liste fra fil og lage et enkelt laguttak.

## Lag en ny fil

Kjør:

```bash
touch laguttak.py
code laguttak.py
```

## Les den ryddede spillerlisten

Bruk `spillere_ryddig.txt` fra forrige oppgave.

Programmet skal:
- lese alle navnene inn i en liste
- sjekke om listen har minst 11 spillere
- skrive ut en melding hvis det er for få spillere
- ellers lage en startellever med de 11 første navnene
- legge resten på benken

Skriv ut:
- overskrift for startellever
- ett navn per linje
- overskrift for benk
- ett navn per linje

## Gjør det litt ryddigere

Lag gjerne en funksjon som skriver ut en liste med navn under en overskrift.

Kjør:

```bash
python3 laguttak.py
```

## Kontrollspørsmål

- Hvorfor må programmet sjekke om det finnes minst 11 spillere?
- Hva er forskjellen på startellever og benk i programmet ditt?
