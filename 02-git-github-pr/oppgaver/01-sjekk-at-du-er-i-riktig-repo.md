# Oppgave 1: Sjekk at du er i riktig repo

I del 1 klonet vi hele kursrepoet fra GitHub. I del 2 skal vi jobbe videre i den klonede mappen.

## Sjekk at du står i riktig mappe

Kjør:

```bash
cd ~/crash-course/informatikk-crash-course
pwd
ls
git status
git remote -v
```

Forklaring:
- `pwd` viser hvor du står.
- `ls` viser filene og mappene.
- `git status` viser om repoet er rent eller har endringer.
- `git remote -v` viser at repoet foreløpig peker til kursholders repo.
