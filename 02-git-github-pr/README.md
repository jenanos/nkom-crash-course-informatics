# Del 2: Mer Python, Git og GitHub

I denne delen skal du fortsette å programmere i Python og etter hvert bruke Git og GitHub på dine egne filer.

Du skal ikke jobbe videre inne i kursrepoet. Kursrepoet er nå oppskriften din. Selve oppgavene løser du i en ny mappe ved siden av den klonede kopien.

Du skal lære å:
- lage en egen arbeidsmappe for Python-oppgaver
- bruke variabler, `if`, funksjoner, lister og løkker
- lese navn fra fil og rydde i tekstdata
- bruke virtuelt miljø i ditt eget prosjekt
- gjøre mappen om til et Git-repo
- pushe til ditt eget private repo på GitHub
- lage branch, commit, push og pull request

## Arbeidsmåte i del 2

- Ha dette repoet åpent som kursmateriell.
- Lag løsningene dine i en egen mappe, for eksempel `~/crash-course/fotballoppgaver`.
- Når Git kommer inn i del 2, er det denne nye mappen du skal gjøre om til ditt eget repo.
