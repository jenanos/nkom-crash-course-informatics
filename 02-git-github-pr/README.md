# Del 2: Git, GitHub og Pull Requests

Denne delen handler om hvordan utviklere henter, endrer og deler kode. Du skal bruke GitHub CLI.

Du skal:
- klone repoet
- bytte remote
- pushe til eget privat repo
- lage branch
- committe
- pushe
- opprette pull request

## Begreper

- **git:** verktøyet som holder styr på historikken i prosjektet
- **GitHub:** nettstedet der repo kan ligge og deles med andre
- **repo:** prosjektmappen med filer og Git-historikk
- **clone:** lage en kopi av et repo ned på egen maskin
- **remote:** koblingen mellom ditt lokale repo og et repo på GitHub
- **origin:** navnet som vanligvis brukes for ditt eget hovedrepo
- **upstream:** navnet som ofte brukes for det opprinnelige repoet du jobber ut fra
- **branch:** et eget spor for endringer
- **commit:** et lagret punkt i historikken
- **push:** sende commits fra maskinen din til GitHub
- **pull request:** en forespørsel om å få endringer inn i en branch
