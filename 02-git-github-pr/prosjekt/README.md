# Tekstverktøy

Dette er et lite Python-prosjekt for Git-øvelser.

Programmet leser en tekstfil og skriver ut enkel statistikk:
- antall linjer
- antall ord
- antall tegn

Forslag til endringer deltakerne kan gjøre:
- endre teksten i `data/eksempeltekst.txt`
- endre utskriften i `main.py`
- legge til telling av setninger
- legge til telling av hvor mange ganger et bestemt ord forekommer
