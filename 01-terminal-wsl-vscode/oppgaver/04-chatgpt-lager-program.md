# Oppgave 4: Bruk ChatGPT til å lage et terminalspill

Målet i denne oppgaven er ikke at du skal skrive all koden selv. Målet er at du skal bruke ChatGPT til å lage kode, lime den inn i en fil og kjøre programmet.

## Slik gjør du det

1. Åpne filen `prompts/terminalspill.txt`.
2. Kopier hele prompten.
3. Lim prompten inn i ChatGPT.
4. Be ChatGPT lage koden.
5. Opprett filen `romskip.py`:

```bash
touch romskip.py
code romskip.py
```

6. Lim inn koden fra ChatGPT i filen.
7. Lagre filen.
8. Kjør programmet:

```bash
python3 romskip.py
```

## Viktig

Du skal lime koden inn i filen `romskip.py`, ikke direkte inn i terminalen.

## Refleksjonsspørsmål

- Hvilken fil ligger koden i?
- Hvilken kommando bruker du for å kjøre filen?
- Hva gjør du hvis programmet feiler?
