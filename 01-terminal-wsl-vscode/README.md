# Del 1: Terminal, WSL, VS Code og Python

Dette er første del av kurset. Målet er å bli trygg på arbeidsflaten du skal bruke når du jobber med kode.

Du skal lære å:
- åpne Ubuntu/WSL
- lage mapper
- flytte ZIP-fil fra Windows til WSL
- unzippe filer
- navigere i terminalen
- lage og lese tekstfiler
- åpne VS Code
- lage og kjøre Python-filer
- bruke ChatGPT til å lage kode
- bruke ChatGPT til feilsøking
- installere en pakke med pip i et virtuelt miljø
