# Del 3: API-er og egne prosjekter

Denne delen handler om API-er. Et API er en avtalt måte for programmer å snakke med andre programmer på.

Du skal:
- hente data fra åpne API-er
- se JSON
- skrive ut utvalgte deler av dataene
- til slutt lage ditt eget API-prosjekt i et nytt repo

## Begreper

- **HTTP:** måten nettlesere og programmer sender forespørsler over nettet på
- **URL:** adressen du spør et API på
- **endpoint:** en bestemt del av et API
- **GET:** en forespørsel for å hente data
- **JSON:** et vanlig tekstformat for data fra API-er
- **statuskode:** tall som forteller hvordan forespørselen gikk
- **header:** ekstra informasjon som sendes med forespørselen eller svaret
- **API-nøkkel:** en hemmelig nøkkel noen API-er krever for tilgang

API-ene i disse øvelsene krever ikke API-nøkkel.
