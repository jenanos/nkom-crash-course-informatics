# Oppgave 6: Lag ditt eget API-prosjekt

Målet er å bruke det du har lært til å lage et lite prosjekt i et nytt repo.

## Forslag til arbeidsflyt

1. Lag en ny mappe for prosjektet ditt.
2. Åpne mappen i VS Code.
3. Lag en `main.py`-fil.
4. Finn et åpent API uten API-nøkkel.
5. Bruk ChatGPT til å lage første versjon av programmet.
6. Kjør programmet.
7. Feilsøk ved behov.
8. Opprett et nytt repo på GitHub og legg prosjektet der.

## Eksempler på små prosjektideer

- hente dagens vær for et sted
- hente helligdager for et valgt år
- søke etter virksomheter i Brreg
- hente en tilfeldig todo eller post fra JSONPlaceholder

## ChatGPT-prompt du kan starte med

```text
Jeg vil lage et lite Python-prosjekt som henter data fra et åpent API uten API-nøkkel.

Mål:
- Programmet skal være enkelt nok for en nybegynner.
- Det skal bruke bare Python standardbibliotek.
- Det skal hente JSON fra et API.
- Det skal skrive ut noen få utvalgte felter på en ryddig måte.

Foreslå 3 enkle prosjektideer, og skriv deretter kode for den enkleste.
Forklar også hvordan jeg lagrer og kjører programmet i Ubuntu/WSL.
```

## Til slutt

Når prosjektet virker:
- lag et nytt GitHub-repo
- legg inn filene
- commit og push
- del repoet med kursholder hvis du blir bedt om det
