# Oppgave 2: Hent data fra JSONPlaceholder

Målet er å hente data fra et enkelt test-API og skrive ut utvalgte felter fra JSON.

JSONPlaceholder er et test-API med falske data. Det er fint for å lære API uten innlogging.

## Slik gjør du det

1. Gå til `startkode`:

```bash
cd 03-api-prosjekt/startkode
```

2. Kjør:

```bash
python3 main.py
```

3. Endre `main.py` slik at programmet skriver ut:
- `title`
- `completed`

Eksempel på ønsket utskrift:

```text
Tittel: delectus aut autem
Fullført: False
```

## ChatGPT-prompt

```text
Jeg har denne Python-koden som henter JSON fra et API. Endre den slik at den skriver ut feltene "title" og "completed" på en ryddig måte. Forklar kort hva du endret.
```
