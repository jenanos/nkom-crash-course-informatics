# Informatikk crash course

Dette repoet er laget for et praktisk crash course i informatikk for ikke-utviklere. Kurset er laget for jurister, økonomer og ingeniører som skal lære praktisk informatikk steg for steg.

Hovedmålet er ikke å gjøre deltakerne til utviklere. Målet er at de skal kunne bruke ChatGPT til å lage, kjøre, feilsøke og vurdere enkle programmer.

Repoet er delt i tre deler:
- **Del 1:** terminal, WSL, VS Code og Python på egen maskin
- **Del 2:** Git, GitHub, brancher, commit og pull request
- **Del 3:** API-er, JSON og et lite eget prosjekt med åpne data

## Slik er flyten i kurset

### Del 1

- Deltakerne får `01-terminal-wsl-vscode` som ZIP på e-post.
- De flytter ZIP-en inn i WSL, unzipper den og jobber lokalt.
- Mot slutten av del 1 installerer de GitHub CLI.
- Til slutt i del 1 kloner de hele repoet.

### Del 2

- Deltakerne jobber i det klonede repoet.
- De lager eget privat repo, endrer remote-oppsett, lager branch, commit, push og pull request.

### Del 3

- Deltakerne lager eget API-prosjekt i et nytt repo.

Det er normalt at du først har en ZIP-kopi av del 1 og senere en klonet kopi av hele repoet. Etter at repoet er klonet, jobber vi videre i den klonede kopien.

## Viktig begrepsforskjell

- **Terminalkommando:** tekst du skriver i terminalen for å be maskinen gjøre noe
- **Python-kode:** tekst som ligger i en `.py`-fil og som Python skal kjøre
- **Fil:** et enkelt dokument, for eksempel `main.py` eller `notat.txt`
- **Mappe:** et sted som inneholder filer og andre mapper
- **Repo:** en prosjektmappe som styres med Git og ofte ligger på GitHub
- **API:** en måte for programmer å hente eller sende data til andre systemer
